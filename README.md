💉 Dependency Injection Demo App

Dependency Injection Demo App is a Kotlin-based Android application created to demonstrate how Dependency Injection (DI) works in real-world Android development. The project focuses on understanding how dependencies are created, provided, and injected into different components instead of creating them directly.

The app demonstrates how DI helps reduce tight coupling, improve code maintainability, promote reusability, and make applications easier to test and scale. It provides a practical implementation that helps developers understand not only what Dependency Injection is, but also why and when it should be used.

✨ Features

* 💉 Dependency Injection implementation
* 🔗 Dependency creation and injection
* 🧩 Loose coupling between components
* ♻️ Reusable and modular code
* 🧪 Improved testability
* 🏗️ Separation of concerns
* 📦 Centralized dependency management
* 📱 Practical Android implementation
* 📈 Scalable project structure
